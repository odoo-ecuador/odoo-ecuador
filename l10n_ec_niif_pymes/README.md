# Plan de cuentas NIIF Pymes

Las cuentas contables serán dividades en diferentes grupos de acuerdo a la actividad, por ejemplo.

NIIF Pymes --> para la base de cuentas contables comunes a todas las empresas.
NIIF Contructores --> para las cuentas contables adicionales a NIIF Pymes que son específicas de empresas de la contrucción.

Para instalar la plantilla de cuentas utilice el módulo l10n_ec_config
